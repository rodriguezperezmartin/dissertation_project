# Dissertation Project — Ph.D. in Public Policy (Economic Policy Cognate)

Private repository tracking all coursework, research, and evolving dissertation work for a Ph.D. in Public Policy, Economic Policy Cognate, at **Liberty University**.

> **Start here every session:** [PROJECT_STATUS.md](PROJECT_STATUS.md) — one file with current status, dissertation objective, methodology, strategy, and a running session log, so nothing has to be reconstructed from scratch.

## Why This Repository Exists
All coursework assignments are being deliberately steered toward one focus area so that every class builds directly toward the dissertation, rather than being disconnected one-off assignments. This repo also tracks professor feedback over time to build an evolving understanding of Liberty University's expectations and evaluation criteria for the Research Concept and the dissertation itself.

## Dissertation Topic (Working)
**Healthcare Digital Infrastructure as a Driver of Public Policy Outcomes in Emerging Economies**

Core research question (working draft): *Does investing in systematic processes that enable nations to capture patient health data enable better public health policy, and does that in turn improve citizens' quality of life and economic resilience?*

This topic exists to serve a set of personal, professional, and faith-driven goals (modernizing healthcare infrastructure, government service/diplomacy, global impact, faith-driven purpose) — the goals drive the research, not the reverse. Full write-up: [dissertation/topic_overview.md](dissertation/topic_overview.md)

## Workflow
1. Each course gets a folder under `coursework/` named by course code (e.g., `PLCY700`); each week gets its own folder (e.g., `week03/`).
2. Within a week's folder: materials go at the top level (`learning_objectives.md`), assignments go in `assignments/` (as markdown), feedback goes in `feedback/`, and any original uploaded files (docx, etc.) are archived in `original_src_files/`.
3. Any insight relevant to the dissertation topic gets pulled into `dissertation/` (topic overview, research question log, or literature review — sorted into `direct_sources/` or `indirect_sources/`).
4. Any insight into how Liberty evaluates work gets logged in `feedback_log/feedback_tracker.md`.
