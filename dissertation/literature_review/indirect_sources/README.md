# Indirect Sources

Sources that shaped your **academic skills, methodology, or general reasoning** through coursework, but are **not directly about** the dissertation topic itself (e.g., a book review assignment evaluating an unrelated book). Useful for methodology citations, but won't anchor the dissertation's core argument.

- `files/` — saved PDFs, named `<AuthorLastName>_<Year>_<ShortTitle>.pdf`
- `annotated_bibliography.md` — entries for every file in `files/`

> If a source later turns out to be more relevant to the dissertation topic than expected, move its entry + file into [../direct_sources/](../direct_sources/).
