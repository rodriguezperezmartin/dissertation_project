# Direct Sources

Sources **directly about the dissertation topic** — healthcare digital infrastructure, digital public infrastructure (DPI), monitoring & evaluation (M&E) systems, health data governance, and public policy in emerging economies. These are the sources you'll cite heavily when actually writing the dissertation chapters.

- `files/` — saved PDFs, named `<AuthorLastName>_<Year>_<ShortTitle>.pdf`
- `annotated_bibliography.md` — entries for every file in `files/`

> Rule of thumb: if a source is about *your topic itself*, it's direct. If it's about general research/writing skills or a topic only tangentially related (e.g., a book review assignment about a book unrelated to healthcare), it belongs in [../indirect_sources/](../indirect_sources/) instead.
