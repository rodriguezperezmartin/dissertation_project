# Capstone Program Requirements — Official Documentation

This folder archives the **official HSOG (Helms School of Government) governing documents** for the Doctor of Public Policy (D.P.P.) capstone/doctoral project process, obtained 2026-10-17.

## Files
- [HSOG_Scholarly_Project_Handbook_2026.pdf](HSOG_Scholarly_Project_Handbook_2026.pdf) — official handbook (effective August 24, 2026), governs the doctoral project process, task progression, and defense requirements.
- [HSOG_Capstone_Template_Fall2024.docx](HSOG_Capstone_Template_Fall2024.docx) — official manuscript template (5-chapter structure, formatting rules, required content per chapter).
- [handbook_summary.md](handbook_summary.md) — structured, searchable markdown summary of the handbook's content (task list, committee roles, defense process, IRB/site rules).
- [template_structure_summary.md](template_structure_summary.md) — structured, searchable markdown summary of the template's 5-chapter manuscript structure and content requirements.

## Why This Matters
These two documents **supersede all prior assumptions** in this repo about the capstone/dissertation process (built before these documents were available). They establish, among other things, that:
- The project must be **site-specific and non-generalizable** — tied to a real organization (e.g., a specific governmental agency, ministry, or NGO) that formally grants site permission, not a cross-country comparative study.
- **Primary data collection is required** (interviews mandatory unless formally exempted, plus a quantitative method) — not just secondary/published data analysis as previously assumed.
- A rigid **16-task progression** governs coursework (PLCY 887–890), each requiring chair/methodologist approval.
- A formal **5-chapter manuscript** (Executive Summary + Chapters 1–5) with specific minimum lengths (Ch. 1 ≥ 25 pages, Ch. 2 ≥ 30 pages, 40+ sources minimum).

See [PROJECT_STATUS.md](../../PROJECT_STATUS.md) and [capstone/topic_overview.md](../topic_overview.md) for how this reshapes the project's direction — a full gap-analysis is being tracked there.
